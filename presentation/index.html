Main direction

Editorial /
Archive in Motion

The main proposal treats the site like a contemporary photography publication: generous image space, strong editorial typography, quiet navigation and a clear path between artistic work, current exhibitions, biography and commissions.

The visual identity can be adjusted later — colours, typography, spacing and image treatment are separated from the site structure so the overall architecture does not need to be rebuilt.
