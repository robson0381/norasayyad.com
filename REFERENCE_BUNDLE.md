# Pacote de referências fornecido

Levantamento do arquivo `Fotos.zip` fornecido para o projeto. As imagens **não são adicionadas ao repositório**, porque grande parte delas é derivada do Instagram e serve apenas como referência de curadoria até a chegada dos originais aprovados.

## Resumo

- 346 arquivos de imagem
- 153 verticais
- 115 quadrados
- 78 horizontais
- formatos/dimensões recorrentes incluem 1440×1440, 1440×1800, 1440×960, 1080×1080 e originais maiores como 3024×4032 / 3072×4096

O conjunto é útil para:

- identificar trabalhos que ainda não aparecem no site;
- escolher possíveis imagens de Home/About para discutir com Nora;
- montar uma lista de originais a solicitar;
- comparar o repertório do Instagram com o portfólio publicado.

Ele **não deve ser tratado como master de produção**.

## Regra para a demonstração

1. Conteúdo já publicado no Squarespace: pode ser referenciado pelo CDN atual como amostra.
2. Conteúdo vindo apenas do pacote/Instagram: fica como referência e não é enviado ao GitHub.
3. Quando Nora aprovar uma imagem, solicitar o original e substituir a referência provisória.
4. Registrar alt text, legenda, crédito, data/local e status de autorização no CMS/metadata final.
